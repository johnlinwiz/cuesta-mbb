# Tests

```sh
make dev       # once: .venv with pytest + Playwright, and headless Chromium
make test      # unit tests: offline, < 1 s
make e2e       # browser tests of docs/index.html: ~10 s
```

CI (`.github/workflows/test.yml`) runs both on every push and pull request. The daily job
(`daily.yml`) runs the unit tests first and stops before fetching scores, commenting on issues or
committing to the Pages site if they fail.

## Unit tests (`tests/unit/`)

They run against **saved copies of last season's (2025-26) pages** in `tests/fixtures/2025-26/`:

| File | Source |
|---|---|
| `team-schedule.html` | cuestaathletics.com team schedule (PrestoSports) |
| `league-gamelog.html` | 3C2A team game log (repeats each game in several stat tables) |
| `league.ics` | 3C2A league iCal feed (trimmed to Cuesta games + a few others) |
| `schedule.yaml`, `venues.yaml`, `drive_times.json` | last season written up as this repo would track it |

Ground truth from those pages: 32 games, 28 scored, **10-18 overall, 5-7 WSC** (the team site's own
record line), OT at San Mateo (Nov 13) and LA Pierce (Jan 24), Shasta (Dec 30) a 2-0 forfeit.
The Hartnell scrimmage `result:` in `schedule.yaml` is made up, to test manual overrides.

`fixtures/refresh_fixtures.py [season]` re-downloads and trims the pages (curl, browser User-Agent).
Tests never touch `data/`: anything that reads or writes repo files gets a temporary root.
GitHub is faked in `test_issues.py` (`gh.api` is replaced), so nothing is sent anywhere.

## Browser tests (`tests/e2e/`)

`docs/` is served locally; `events.json` is generated by `scripts/build.py` from the frozen copy of
this season's data in `tests/e2e/data/` plus **made-up results** (`results.json`: L 68-75, W 81-74 OT,
W forfeit), and the clock is pinned to 2026-11-05 noon PT. Every request leaving 127.0.0.1 is
intercepted: Leaflet and FullCalendar come from `tests/e2e/vendor/` (byte-identical to the CDN
files — a test checks them against the page's `integrity=` hashes, so bumping a CDN version means
re-downloading it there), OpenStreetMap tiles get a blank PNG, Nominatim and OSRM get canned answers,
and any other outside request fails the test. Phone tests use a 390 px touch viewport.
